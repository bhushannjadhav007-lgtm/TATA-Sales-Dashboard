# 📊 TATA Sales Dashboard Project

## 📌 Project Overview

This project focuses on analyzing sales data and building an interactive dashboard to generate meaningful business insights. It helps in understanding sales performance, identifying trends, and supporting data-driven decisions.

---

## 📁 Files Included

* **TATA Sales Data.xlsx** – Raw dataset used for analysis
* **TATA Project.sql** – SQL queries for data processing
* **TATA Sales Performance Dashboard.pbix** – Power BI dashboard

---

## 🛠️ Tools & Technologies

* Microsoft Excel
* SQL
* Power BI

---

## 📈 Key Features

✔ Data Cleaning & Preparation (Excel)
✔ Data Analysis using SQL
✔ Interactive Dashboard (Power BI)
✔ Sales Trends & Performance Insights

---

## 🎯 Objectives

* Analyze sales performance
* Identify patterns and trends
* Build a user-friendly dashboard
